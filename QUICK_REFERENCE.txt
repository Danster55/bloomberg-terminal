STEP-BY-STEP DEPLOYMENT:
────────────────────────

1️⃣  CREATE GITHUB REPO (5 mins)
   • Go to github.com → Click "New"
   • Name: "bloomberg-terminal"
   • Make PUBLIC
   • Click "Create repository"
   ✅ You now have an empty GitHub repo

2️⃣  DOWNLOAD & SETUP (2 mins)
   • Download all these files I created:
     - SETUP_GUIDE.md
     - README.md
     - index.html
     - netlify.toml
     - package.json
     - .gitignore
     - netlify/functions/stock-data.js (create folder first)

   • Folder structure should be EXACT (see above)

3️⃣  PUSH TO GITHUB (2 mins)
   In terminal:
   ```
   cd bloomberg-terminal
   git add .
   git commit -m "Initial commit: Bloomberg Terminal"
   git push origin main
   ```
   ✅ Your code is now on GitHub

4️⃣  CONNECT NETLIFY (3 mins)
   • Go to netlify.com → Sign in
   • Click "Add new site"
   • Click "Import an existing project"
   • Select "GitHub"
   • Authorize Netlify to access your account
   • Select "bloomberg-terminal" repo
   • Click "Deploy site"
   ✅ Netlify is now building your site (2-3 mins)

5️⃣  ADD YOUR FINNHUB API KEY (1 min) — CRITICAL!
   In Netlify dashboard:
   • Click your site name
   • Go to "Site settings"
   • Click "Build & deploy" → "Environment"
   • Click "Edit variables"
   • Add new variable:
     KEY:   FINNHUB_API_KEY
     VALUE: d9nms3hr01qvumgb10m0d9nms3hr01qvumgb10mg
   • Click "Save"
   ✅ Your API key is now secure in Netlify

6️⃣  VERIFY LIVE (2 mins)
   • Netlify gives you a URL (e.g., bloomberg-terminal-xyz.netlify.app)
   • Click it
   • You should see: Terminal loading ✓
   • Click "DAN ISA COMBINED" ✓
   • Watch live data load (P/E, dividends, earnings) ✓
   ✅ YOUR TERMINAL IS LIVE!
